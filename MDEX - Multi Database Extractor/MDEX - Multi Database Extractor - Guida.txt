MDEX - Multi Database Extractor
Guida Utente
Versione: 1.0
Descrizione
MDEX (Multi Database Extractor) è uno strumento Python che consente di:

connettersi a Oracle o Microsoft SQL Server;
eseguire una o più query SQL presenti su file;
esportare i risultati in formato CSV o XLSX;
generare report di esecuzione;
registrare log dettagliati delle operazioni effettuate.

Requisiti
Python
Verificare che Python sia installato:
Shell
python --version
Installazione

Creare il Virtual Environment

Nella cartella MDEX:
Shell
python -m venv .venv
Attivazione Windows:
Shell
.venv\Scripts\activate
Attivazione Linux:
Shell
source .venv/bin/activate

Installare i package

Shell
pip install -r requirements.txt
Struttura Cartelle
Al primo avvio vengono creati automaticamente:
config.json, queries [oracle; sqlserver], output, reports, logs
Avvio Applicazione
Lanciare il programma:
Shell
python mdex.py
Configurazione Database
Dal menu principale selezionare:
Configura connessione
Configurazione Oracle
Esempio:
Database          : Oracle
Host              : oracle-server
Porta             : 1521
Service Name      : ORCL
Utente            : export_user
Configurazione SQL Server
Esempio:
Database          : SQL Server
Host              : sqlserver01
Porta             : 1433
Database Name     : DWH
Utente            : export_user
Password
Per motivi di sicurezza la password:

non viene salvata nel file config.json;
viene richiesta ad ogni esecuzione.

Posizionamento Query SQL
Le query devono essere salvate nella cartella:
queries
oppure nelle sottocartelle:
oracle - sqlserver
Autodiscovery Query
MDEX ricerca automaticamente tutte le query:
*.sql
presenti nella cartella configurata e nelle relative sottocartelle.
Non è necessario modificare il codice quando vengono aggiunte nuove query.

N.B.Le query devono contenere controlli sulle date:
--> es. Oracle
SELECT *
FROM Tabella
WHERE DATA_EVENTO >= TO_DATE(:inizio,'YYYY-MM-DD HH24:MI:SS')
AND DATA_EVENTO < TO_DATE(:fine,'YYYY-MM-DD HH24:MI:SS')

--> es.SQL
SELECT *
FROM Tabella
WHERE DATA_EVENTO >= @data
AND DATA_EVENTO < @data

Elenco Query
Dal menu:
Elenca query
vengono mostrate tutte le query trovate.
Selezione Query
Dal menu:
Eseguire tutte le query
ALL
Eseguire query specifiche
1,3,5
Eseguire un intervallo
1-4
Eseguire una selezione mista
1,3-5,8
Test Connessione
Dal menu:
Test connessione
Verifica:

raggiungibilità del database;
validità delle credenziali;
data del server;
versione del database.

Esempio:
[OK] Connessione riuscita
Versione DB :
Oracle Database 19c
Data DB :
2026-03-26 10:15:22
Avvio Estrazione
Dal menu:
Esegui estrazione
Specificare:
Data/Ora inizio:
2026-03-26 06:00:00
Data/Ora fine:
2026-03-27 06:00:00
Output CSV
Esempio:
nomequery_data.csv
Output Excel
Se configurato XLSX:
nomequery_data.xlsx
Log Applicativo
Tutte le operazioni vengono registrate in:
logs/execution.log
Esempio:
2026-03-26 10:00:01 INFO Avvio applicazione
2026-03-26 10:00:05 INFO Connessione Oracle OK
2026-03-26 10:00:12 INFO Avvio query NOME_QUERY
2026-03-26 10:00:30 INFO Query completata
Report Finale
Al termine dell'esecuzione vengono generati:
reports/report_YYYYMMDD_HHMMSS.txt
e
reports/report_YYYYMMDD_HHMMSS.xlsx
Contenuto Report
Per ogni query vengono riportati:

nome query;
numero record estratti;
durata esecuzione;
esito;
eventuale messaggio di errore.

Esempio:
QUERY         RIGHE      TEMPO      ESITO
NomeQuery     125000     15.2 sec   OK
NomeQuery     124500     14.9 sec   OK
NomeQuery     0          0.4 sec    KO
Risoluzione Problemi

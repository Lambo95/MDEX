# MDEX

Multi Database Extractor

Tool Python per l'esecuzione automatizzata di query SQL ed esportazione risultati in CSV o XLSX.

Database supportati:

- Oracle
- Microsoft SQL Server

---

# Funzionalità

- Configurazione persistente tramite config.json
- Test connessione database
- Autodiscovery delle query SQL
- Selezione query da menu
- Export CSV
- Export XLSX
- Logging completo
- Report finale TXT
- Report finale XLSX

---

# Requisiti

Python 3.11+

Installazione dipendenze:
da bash o powershell
-> pip install -r requirements.txt

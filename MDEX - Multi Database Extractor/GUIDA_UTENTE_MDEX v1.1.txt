MDEX - Multi Database Extractor

Guida Utente

Versione: 1.1

------------------------------------------------------------
DESCRIZIONE
------------------------------------------------------------

MDEX (Multi Database Extractor) è uno strumento Python che
consente di:

- connettersi a Oracle o Microsoft SQL Server;
- eseguire una o più query SQL presenti su file;
- esportare i risultati in formato CSV o XLSX;
- generare report di esecuzione;
- registrare log dettagliati delle operazioni effettuate;
- eseguire estrazioni giornaliere automatiche;
- evitare riesecuzioni tramite controllo file esistenti;
- consolidare file CSV generati in più intervalli.

------------------------------------------------------------
REQUISITI
------------------------------------------------------------

Python

Verificare che Python sia installato:

python --version

Python 3.11 o superiore

POSIZIONAMENTO QUERY SQL
------------------------------------------------------------

oppure

------------------------------------------------------------
AUTODISCOVERY QUERY
------------------------------------------------------------

MDEX ricerca automaticamente tutte le query:

*.sql

presenti nella cartella configurata e nelle relative
sottocartelle.

Non è necessario modificare il codice quando vengono aggiunte
nuove query.

------------------------------------------------------------
PARAMETRI DATA
------------------------------------------------------------

Le query devono contenere i parametri:

Oracle

SELECT *
FROM TAB_TEST
WHERE DATA_EVENTO >= TO_DATE(:inizio,'YYYY-MM-DD HH24:MI:SS')
AND DATA_EVENTO < TO_DATE(:fine,'YYYY-MM-DD HH24:MI:SS')

SQL Server

SELECT *
FROM TAB_TEST
WHERE DATA_EVENTO >= ?
AND DATA_EVENTO < ?

------------------------------------------------------------
MODALITA' ESTRAZIONE
------------------------------------------------------------

Menu:

6 - Modalità estrazione

1 - File unico
2 - File giornalieri

------------------------------------------------------------
MODALITA' FILE UNICO
------------------------------------------------------------

Viene eseguita una sola query sull'intero periodo.

Esempio:

Inizio:
2026-08-23 06:00:00

Fine:
2026-08-23 12:00:00

Output:

AWB_IN_20260823_060000_20260823_120000.csv

------------------------------------------------------------
MODALITA' FILE GIORNALIERI
------------------------------------------------------------

Per ogni giorno viene eseguita una query separata.

Esempio:

Periodo:

2026-08-21 06:00:00
2026-08-24 06:00:00

Output:

AWB_IN_20260821.csv
AWB_IN_20260822.csv
AWB_IN_20260823.csv

Tra una query e la successiva viene rispettato il parametro:

sleep_seconds

------------------------------------------------------------
SKIP AUTOMATICO
------------------------------------------------------------

Se il file esiste già:

la query NON viene rieseguita.

Nel report verrà visualizzato:

SKIPPED

Questo permette di riprendere facilmente
estrazioni interrotte.

------------------------------------------------------------
CONSOLIDAMENTO CSV
------------------------------------------------------------

Menu:

8 - Consolida CSV

Permette di unire più file CSV appartenenti
alla stessa query.

Esempio:

AWB_IN_20260823_060000_20260823_120000.csv

AWB_IN_20260823_120000_20260823_180000.csv

AWB_IN_20260823_180000_20260824_000000.csv

Vengono consolidati in:

AWB_IN_20260823.csv

Gli header vengono mantenuti una sola volta.

------------------------------------------------------------
RISOLUZIONE PROBLEMI
------------------------------------------------------------

Errore Oracle

Verificare:

- Host
- Porta
- Service Name
- Username
- Password

Errore SQL Server

Verificare:

- Host
- Porta
- Database
- Username
- Password

Nessuna Query Trovata

Verificare la presenza di file:

*.sql

nella cartella configurata.

Errore Esportazione

Verificare:

- permessi di scrittura
- spazio disco
- file aperti in Excel
